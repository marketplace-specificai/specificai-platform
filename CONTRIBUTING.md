# Contributing

This repository is generated. A sync bot republishes every file here from
SpecificAI's private sources on each chart release, so pull requests against
it cannot be accepted — any change merged here would be overwritten by the
next sync.

To report a problem or request a change, contact your SpecificAI
representative or write to `devops@specific.ai`. For suspected security
issues, follow [SECURITY.md](SECURITY.md).
