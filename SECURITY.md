# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities in the SpecificAI Platform, its Helm chart,
or the content of this repository privately to **devops@specific.ai**.
Include what you found, where, and how to reproduce it; we will confirm
receipt and keep you informed while it is investigated.

Please do not disclose the issue publicly before it is resolved. Issues are
disabled on this repository, and its content is generated — a public pull
request cannot carry a fix.
